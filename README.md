# INSGC_Movement
Our INSGC research project has two main parts:
1. **The simulation**: This part is not included in this repository, but is what we run our movement scripts with.
2. **Movement and Intteruption**: This part is what our github contains. Currently there are 4 seperate interruption scripts for the 4 seperate trials, 2 loggers for urgency and priority trials, and 3 other python scripts (server, bot, and Tasks) for the internal robot-server communication.

This repo serves as the main place to host all of our other scripts that are not the simulation itself.
